# Dev Story 10.9 — Discovery pack page `/packs/disc.html`

## Scope

Story 10.9 ships the Discovery pack page at `/packs/disc.html` — the destination
for the home-grid "Discover Me" lane (Story 10.8) and the landing route for
every Discovery quiz. The page renders the 6 quizzes (spirit-animal, future-
partner, what-would-you-do, decision-style, friend-match, car-finder) as a
`.discovery-pack-grid` of `.discovery-pack-card` tiles, each linking to the
per-quiz route at `./discovery/<slug>/index.html`. The chrome is sourced from
`assets/shell/chrome.html` (header/footer/palette/settings/help) and the body
mirrors the existing `/packs/<slug>.html` skeleton — same `pack-page-header`
shape, swapped content slots for discovery.

## Acceptance criteria

1. `packs/disc.html` exists on disk and is generated by
   `scripts/generate-pack-pages.py` (the script auto-discovers via the
   `DISCOVERY_PACK` descriptor; idempotent re-runs are no-op).
2. The page loads `assets/js/disc-page.js` (NOT `assets/js/pack-page.js`) —
   the discovery renderer reads `data.packs.discovery.entries[]`, not
   `tools[].pack[]`.
3. The page includes `assets/css/discovery.css` (the `.discovery-pack-grid`
   + `.discovery-pack-card` chrome from Story 10.6).
4. `assets/js/disc-page.js` exposes a frozen `HT.discPage = { render,
   entries, ready, version }` value (AD-14 read-only contract at the value
   level — mirrors `pack-page.js` / `pack-grid.js` pattern).
5. `HT.discPage.render()` resolves to 6 frozen card entries that link to
   `./discovery/<slug>/index.html`. Missing/malformed entries are filtered
   out (no throw).
6. The renderer does NOT eagerly load `assets/js/scoring.js`,
   `assets/js/results.js`, `assets/js/challenge.js`, `assets/js/recommend.js`,
   or `assets/js/catalog.js`. Each is page-conditional via the discovery
   loader (`HT.discovery.load()`).
7. `disc-page.js` is listed in `scripts/bundle-size-gate.py`'s
   `SPEC_PAGE_CONDITIONAL_MODULES` (NOT `SPEC_JS_MODULES` — the home page
   stays slim).
8. `shell-drift-check.py` exits 0 — the new page matches the canonical
   chrome (header / footer / palette / settings / help / skip landmark /
   `ht-lazy.js` + `shell-thin.js` Tier-1 anchors).
9. `bundle-size-gate.py` exits 0 — gzipped `disc-page.js` ≤ 4 KB.
